# Фото для фейковых пользователей

- `people/` — фото для анкет (по одному на человека, первые 10 — ищущим, следующие 10 — хозяевам).
- `rooms/` — фото комнат (по 3 на объявление, берутся по кругу).

Подходят .jpg, .jpeg, .png, .webp. Фото сжимаются и очищаются от EXIF так же, как загруженные людьми.
Используйте только фото, которые разрешено использовать (например, с unsplash.com),
а для лиц — сгенерированные лица несуществующих людей.
